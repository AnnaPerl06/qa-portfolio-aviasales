# Тестирование веб-приложения Aviasales 

В этом репозитории представлена тестовая документация, подготовленная в рамках функционального и UI-тестирования сервиса поиска авиабилетов [Aviasales](https://aviasales.ru).

## 🎯 Цели и область тестирования
* Проверка основного пользовательского сценария (поиск билетов по заданному направлению и датам).
* Тестирование работы фильтров и сортировки в результатах выдачи (пересадки, багаж, время вылета, авиакомпании).
* Проверка валидации обязательных полей формы поиска (позитивные и негативные сценарии).
* Проверка верстки и корректного отображения элементов интерфейса в браузере.

## 📂 Тестовая документация
Вся документация оформлена в структурированной Google Таблице (доступна для просмотра по ссылке):

* 📋 **[Чек-лист (Check-list)](https://docs.google.com/spreadsheets/d/1zI9IgUcN_qcng6Ki0mjycRo0VnSN-gz353OovroYMCU/edit?usp=sharing))** — список проверок ключевых модулей формы поиска и страницы выдачи.
* 📝 **[Тест-кейсы (Test Cases)](https://docs.google.com/spreadsheets/d/1zI9IgUcN_qcng6Ki0mjycRo0VnSN-gz353OovroYMCU/edit?usp=sharing)** — подробные сценарии с предусловиями, шагами воспроизведения и ожидаемым результатом.
* 🐞 **[Баг-репорт (Bug Report)](https://docs.google.com/spreadsheets/d/1zI9IgUcN_qcng6Ki0mjycRo0VnSN-gz353OovroYMCU/edit?usp=sharing)** — детальное описание найденных дефектов с указанием серьезности (Severity) и окружения.

## 🐛 Пример найденного дефекта
* **Заголовок:** В результатах поиска отображается рейс с пересадкой при активном фильтре «Без пересадок» на странице выдачи билетов.
* **Severity:** Major. 
* **Окружение:** Windows 10 PRO, Chromium-Gost 133.0.6943.98.

## 🛠 Использованные инструменты
* **Google Sheets** — составление чек-листов, тест-кейсов и баг-репортов.
